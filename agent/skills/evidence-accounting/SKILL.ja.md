# 証拠の記帳

選択は、書き留められなければ目に見えない。このスキルは、その「書き留める」こと自体である：データへのあらゆる目配り、あらゆる検定、あらゆる引用が台帳に1行を残し、後の主張に正直な値付けができるようにする。

## 3つの台帳

1. **全体試行回数（N）**：データに対する仮説の検定はすべて、プロジェクト全体で1つのカウンタを増やす——「ちょっと見ただけ」の検定も、共有データ上で他ラインが走らせた検定も含む。N は決してリセットされない。新しいセッション、新しいリポジトリ、新しい年のためにも。
2. **曝露レジストリ**：データセット／セグメントごとに、誰が・何を・どの方向に・いつ読んだかを記録する。方向を読むために開かれたセグメントは「既見」とマークされ、そこからの結論は、引用される場所すべてでそのマークを付けられる。
3. **既見方向と再利用の値付け**：すでに開かれたセグメントの再利用は許され、値付けされる（例：*そのセグメント*の再利用のたびにハードルが上がるキューフィー）。禁じられるのは、再利用を初見として提示することである。

## 運用ルール

- 方向を読む**前**に登録する。後ではない。結果が分かったあとに書かれた登録は「遅刻」とマークされ、遅刻マークは下流のすべての証拠レベルを引き下げる。
- 引用には、その証拠レベル（探索的／レビュー済み／独立に確認済み／前向き）と曝露マークを伴わなければならない。これらを伴わない数字は、何度繰り返し引用されていようと未検証として扱われる。
- 失敗した検定も放棄された検定も、結果とともに台帳に残る。失敗を削除することは唯一許されない編集である：それは、その後台帳から計算されるすべての率を偽造する。
- 数字が訂正されたら、訂正は伝播する：古い値を引用していたページはすべて、訂正が着地するのと同じコミットの中で更新対象としてフラグを立てられる。
