# ツールカード（新しいツールごとに1ページ）

```text
ツール名：
クラス：甲（表示と推導） / 乙（判定と採点） / 丙（詰まりどころの課題化）
何を解決するか：これがないと、どの類の問題が手も足も出ないか / 判定できないか
原理：式を一度書き、白話でもう一度書く（誰が払うのか、なぜその金があるのか、いつ失効するか——領域に応じて置き換える）
既知答え：手計算できる小さい例 + 期待出力（実課題の前にまずこれを通す）
変異は必ず失敗すること：わざと壊す箇所を一つ + テストが赤にならなければならない位置
使った実課題：どの課題で、どの判断を変えたか（なければ「まだ」と書く。「まもなく」とは書かない）
適用境界：モデルクラス / データ条件 / 失効するケース
```
