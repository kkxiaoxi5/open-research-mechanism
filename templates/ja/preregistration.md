# 事前登録ページ（結果を見る前にコミットし、バージョンのタイムスタンプが証拠になる）

```text
命題：一文
仕組み：誰が、なぜ、どんな制約のもとで、体系的に我々に有利な行動を取るのか
事前予測：方向 + 数量級 + 時間窓
検出力：SE の出所、クラスタリングの口径、MDE。MDE > 予測効果なら、本ページは探索登録としてのみ扱う
判定基準：成立条件 / 否定条件（いずれも事前に固定した数値またはルール）
データと露出：どの区間のデータを使うか。その区間の露出状態（未見 / 方向のみ既見 / 開封済み）
試行カウント：本試行を登録した後のグローバル N の増分
コスト口径：バージョン。実測していないものは「仮定」と明記する
再開条件：否定された場合、どんな新しい情報が出れば再開できるか
```
