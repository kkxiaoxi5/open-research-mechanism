# 認領カード（課題を出すときに使う）

```text
カード番号：<ライン>-<番号>（例：A-012 / C-003）
出典：命題番号 / 原話番号 / 上位カード番号
課題：一文で、何に答えるのかを明確に書く
事前予測：数量級つきの予測。「結果が X なら、どの判断が変わるか」を明記する
入力バージョン：データ / 仕様のバージョンまたはコミット番号（取れない場合は「未定」と書き、理由を添える）
検収方法：既知答え / ビット単位の再現 / 機械判定スクリプト（少なくとも一つ、明記する）
審査者：作者以外を指名する
計算資源と枠：予想使用量。他ラインと共有するリソースは先にチャネルで一言断る
詰まったとき：詰まりどころを三文で書き、別角度の子課題を自動生成する（空待ち禁止）
```
