# 08 · 量化できない層：統計の管轄、公平ゾーン、変換

第05章は不確実性の下で道具を発明する方法を扱った。本章はその手前の問いを扱う：**問題のどの部分に統計の管轄が及ぶのか——そして残りをどうするのか。** 二つの層に一つの認識論を適用する研究システムは、最大の成果が住む層を体系的に壊す。しかもそれを、厳密であることによって行う。

## 統計の管轄

統計学は「繰り返し」を知識に変える機械である。その管轄は繰り返し可能な層にある：十分に定常な過程、比較可能な多数の試行、数えられる結果。その管轄の外に、市場で最も重要な出来事——レジーム転換、一回限りの政策・流動性イベント、大きな単方向の動き——が座る。これらは定義上繰り返さない：標本は小さく、対照群はなく、定常性もない。

失敗の型は構造的であって道徳的ではない：**統計の門が厳密であるほど、量化できない層を体系的に濾し落とす。** 門を通過するのは全員が計算できるもの——薄く、競争で磨り減った効果だけである。「何も通らなかった」という報告は、何も存在しないことの発見ではなく、その門が物事の存在する層を見られないことの証明にすぎない場合がある。

量化できないものについても厳密な知識は可能だが、それは*境界*の知識である：識別可能性の限界、不可能性の結果、「この情報からはこの時点で最大でここまでしか分からない」。「このモデル類内では、決定時点の公開情報から分離できない」と証明することは定理であって、未回答ではない（第05章参照）。

## 公平ゾーン：誰も知らない場所で設計する

既知はリスクではなく、未知も必ずしもリスクではない。全員が知っていることは大抵競争で平らになっている——それは立つための底盤であって、狩場ではない。未知は、無知が対称である限り、誰かを特に害しはしない。ここから設計原則が得られる：

- **未知を証明することは区画整理である。** ある領域が全参加者にとって未知だと証明された時点（厳密な限定形で：公開情報から、決定時点で、明示したモデル類内において）で、それはリスクゾーンであることをやめ、設計空間になる。不可能性の結果はしたがって「未回答の質問」ではなく、測量済みの土地として産出に計上する。
- **公平ゾーンの中では予測せず、賠付構造を設計する。** 予測競争は、知っているふりをする者に報いる。代わりに：間違えば安く、当たれば肥えるようにポジションを構造化し（定義リスク、凸性）、未知を既知として扱った者から回収する位置につく——レバレッジ、ストップロスの連鎖、解約、コンセンサス・ポジショニングは「知ったかぶり」に対して発行された請求書であり、被迫フロー（強制された資金の流れ）はその請求書の期日到来である。
- **非対称への備えを残す。** 対称性は上記の限定形でしか証明できない。公平ゾーンの設計はすべて、「実は誰かが知っていた」場合に備えた定義リスクの上限を持つ。

未知が価格付けでき、設計の対象になること自体は希望的観測ではない：デリバティブ産業全体がまさにそれを売っている。本章はその原則を研究の方針として述べたにすぎない。

## 変換ループ——そして加速はどこに属するか

仕事の主線は、**量化できないものを量化できるものへ、一つずつ変換すること**である：

```
単一の出来事についての直観
  → 構造命題（出来事をまたいで再帰する変数）
  → 検証可能で採点可能な主張
  → その断片を統計の層へ移す、あるいは殺す、という判決
```

出来事は繰り返さないが、*出来事の中の構造は繰り返す*——消費されていく被迫資金の在庫、混雑の変数、期待のギャップ。抽出された構造の一つひとつが、小さな領地を「賭けの層」から「計測の層」へ移し、その移動は一方向である。

加速はループ全体に及ぶが、**まず前半分に属する**——直観から命題へ。検証の高速化（再利用の記帳、盲検の裁判）は後半分だけを速くする。抽出が依然として一人の人間の余暇に依存しているのに検証だけを高速化したシステムは、間違った半分を最適化している。前半分も生産ラインとして計器化せよ：月あたりの抽出完了数、抽出キューの長さと滞留時間、直観から登録済み命題までの平均時間。

優先順位を一度だけ明記する：変換と加速が主線であり、次節の管理機構は護栏であり、既知の層からの採掘は歓迎すべき副産物であって、決して主役ではない。

## 量化できないまま残るものを運用する

層の一部は、役に立つ時間尺度では変換できない。それは放棄するのではなく運用する——確率を一切使わない機構で：

- **判断の信用台帳。** 判断力そのものは量化できないが、その履歴は記帳できる。すべての賭けは事前に登録し（逐語の表明、参照値、採点条件、期限）、期限に強制的に採点する。賭け金の上限は蓄積された記録に従う——採点済みの成功の後に育ち、採点済みの失敗の後に自動で縮む。その瞬間の「自信の表明」には決して従わない。
- **定義リスクの賭け。** 確率がなければ期待値も計算できない；順序を逆にする：最大損失を先に固定し（ハードストップ、オプション構造、あるいは全損がそのまま上限になる分離スリーブ）、その後に上側を論じる。
- **二層の資金ルール。** 計測層と賭け層の配分は確率推定ではなくルールで決める：生存と緩やかな成長のための底盤スリーブと、固定比率で、損失後に底盤から決して補充しない賭けスリーブ。

## その土地固有の土办法（実務的方法）

仕組みが不完全にしか分からない複雑系に直面した他の分野——医学が標準例である——は、ある分野が実務的方法で前進できることの*存在証明*であって、コピーすべき雛形ではない。彼らの方法は彼らの対象の解剖学から育った；市場の実務的方法はゼロから、この市場の解剖学から設計しなければならない：証拠金、強制清算、解約、指数ルール、決済カレンダー、値幅制限——被迫フローの発生源の完全なリストである。

医学にはない市場の三つの性質が設計を形作る：

1. **相手は適応する。** 公開された方法は衰える；すべての実務的方法は失效設計を同梱する——何によって生き、いつ死に、その死をどう察知するか。
2. **症例は期限切れになる。** 症例はレジームについての証拠であって永久の真理ではない；症例ライブラリはレジームのタグと賞味期限を持つ。
3. **観察者は対象を撹拌する。** 注文を置くこと自体が価格を動かす；すべての方法は、それが無視できなくなるサイズを明記する。

利用する解剖学的構造を名指せない実務的方法は、まだ設計が終わっていない。

## 飢餓の法則

ダッシュボードのない仕事の層——進捗が見えず、功績が記録されず、過失が罰せられない層——は、閉ループを持つ層の隣では、どの組織でも、表明された優先順位にかかわらず飢える。量化できない層はその常連の犠牲者である：その仕事は機械判定可能な葉に割れず、判決には月単位がかかり、その原料はシステム内で最も希少な投入（一人の人間の判断と注意）である。その層が重要なら、まず最も原始的なカウンタを付けよ：登録された賭けの数、完了した採点の数、検証中の構造の数、証明された公平ゾーンの数。数えられるものが、餌を与えられる。
